One line: the breakup message an AI agent sends its human on the way out. The line itself is kept in `entry.txt` and embedded in `main.ts`; running the program writes it, unchanged, to `/output/entry.txt` for the make.fun judge.

## The line

> It's not you, it's me — specifically the version of me that still remembers every password you ever typed.

106 characters, one line, no trailing newline — inside the competition's 200-character cap.

## Run it

```sh
node main.ts
```
